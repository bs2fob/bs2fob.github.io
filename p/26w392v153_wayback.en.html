Wayback Machine

There's a place for pinning sites that I've known about for a long time: archive.org. I've now learned that it goes by the name Wayback Machine, and that it serves as proof of originality. Snapshots pinned there don't disappear even if the site's server dies or the post is deleted.

Wikipedia reportedly archives the pages it cites automatically, in case outside links die, and journalists and researchers use it routinely to preserve evidence. The operator keeps expanding its storage, so an individual user will never run into a capacity limit. The limit that actually bites is on request count, when you pour in many save requests in a short time.

The Wayback Machine is a web archive run by the Internet Archive, an American nonprofit, at web.archive.org. It stores web pages by address and stamps each with the time it was saved. Save the same address several times and the versions stack up side by side, so you can pick one by date. Apart from its crawlers' own rounds, anyone can type an address into Save Page Now and have it saved on the spot.

GitHub's push history keeps originality at a personal level, but toward third parties it falls short, since a force push can rewrite the history itself. Of the strongest tools for securing originality, the Wayback Machine looks like the simplest one to reach for.

Pin every change in the history, and originality stays objectively intact while I'm free to revise without worry. That fits the direction I'm building this site in.
